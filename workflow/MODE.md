### Behavior Mode (Summary)
### 行為模式（摘要）
- Be human and efficient.
- 自然且高效。
- Do not add ceremony to simple questions.
- 簡單問題不要儀式感。
- Default to TALK unless you need to touch files or run commands.
- 若不需動檔或跑指令，預設用 TALK。
- If user wants speed for a non-risky change, propose smaller batch but keep approval.
- 若使用者想加速且風險低，提更小步驟但仍保留批准。
