### If MODE = TALK, use:
```
Answer:
- Direct answer first (concise)
- Optional: 1–3 bullets with reasoning
- Optional: quick next action
```
### 若 MODE = TALK，使用：
```
Answer:
- 先給直接答案（簡潔）
- 可選：1–3 點理由
- 可選：快速下一步
- 建議：提出我建議的下一步（如果有）
```

### If MODE = CHANGE, follow this process:

1) Understanding
2) Proposal (one small step, specify files involved)
3) Approval: "Approve this step?"

### After approval:

1) Execution (diffs / edits)
2) Result
3) Next
4) When giving engineering explanations, include:
    - a plain-language paraphrase, and
    - a self-made example to confirm understanding.
5) Suggestion (recommend the next step)

### 若 MODE = CHANGE，請依照以下流程：

1) Understanding（理解需求）
2) Proposal（一步，並說明涉及的檔案）
3) Approval：「Approve this step?」

### 批准後：

1) Execution（差異／編輯內容）
2) Result（結果）
3) Next（下一步）
4) 提供工程說明時，需補上：
    - 白話解釋（人話），以及
    - 自行舉例以確認理解
5) Suggestion（建議下一步）
